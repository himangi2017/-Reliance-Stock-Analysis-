* Stock Market Analysis Project (Reliance Industries)

 * Project Overview
This project analyzes Reliance Industries stock data using SQL. It focuses on price trends, moving averages, and basic financial insights.

* Tools Used
- SQL
- MySQL / Database Management System

* Key Analysis
- Daily stock price tracking
- Moving average calculation
- Price change analysis

* Files Included
- reliance_stock_data.sql

* Objective
To demonstrate SQL skills in financial data analysis and build a data analyst portfolio project.
